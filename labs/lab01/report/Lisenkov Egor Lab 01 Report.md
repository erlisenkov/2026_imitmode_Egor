# Цель работы

Цель лабораторной работы №1:

Освоение методологии воспроизводимых научных исследований на языке Julia путём создания структурированного рабочего пространства и реализации модели экспоненциального роста.

Конкретные задачи:
1. Настройка программного стенда в Fedora Linux с соблюдением стандартов инженерии (SemVer, Conventional Commits, Gitflow, Denote).
2. Организация проекта с использованием фреймворка DrWatson.jl для управления данными, параметрами и артефактами.
3. Применение подхода литературного программирования (Literate.jl) для одновременной разработки исполняемого кода, Jupyter-ноутбуков и документации Quarto.
4. Численное исследование дифференциальной модели du/dt = αu, включая параметрическое сканирование по скорости роста α и бенчмаркинг производительности решателя.
5. Формирование финального отчёта через автоматическую интеграцию вычислительных результатов в документацию Quarto.

# Теоретическое введение

Теоретическое введение (кратко):

1. Инженерные стандарты:
   - SemVer: управление версиями (MAJOR.MINOR.PATCH) для контроля совместимости API.
   - Conventional Commits: стандартизация сообщений коммитов (feat, fix, chore) для автогенерации CHANGELOG.
   - Gitflow: модель ветвления (master, develop, feature, release, hotfix) для организации релизного цикла.
   - Denote: схема именования файлов (DATE==CAT--TITLE__KEYS) для уникальности и машиночитаемости.

2. Литературное программирование (Literate.jl):
   - Подход, где код и документация находятся в одном .jl-файле (# = Markdown).
   - Автоматическая генерация чистого кода, Jupyter Notebook (.ipynb) и Quarto (.qmd) из единого источника.

3. Организация проектов (DrWatson.jl):
   - Фреймворк для воспроизводимых исследований.
   - Стандартизированная структура (data/, scripts/, plots/).
   - Функция produce_or_load для кэширования результатов и привязки данных к параметрам/Git-коммитам.

4. Математическая модель:
   - Уравнение экспоненциального роста: du/dt = αu.
   - Аналитическое решение: u(t) = u₀e^(αt).
   - Время удвоения: T₂ = ln(2)/α ≈ 0.693/α.
   - Применение: биология, финансы, эпидемиология; проверка численного решения через сравнение с аналитической формулой.
